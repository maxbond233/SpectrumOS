# RFC 001：持久化研究工作流

状态：用户已在项目重构对话中确认实施。

目标版本：0.5.0。

## 背景

研究任务需要能够暂停审核、恢复执行、追溯证据，并将模型调用费用与具体运行关联。

## 设计

- FastAPI 提供业务接口与 SSE，Next.js 提供中文研究工作台。
- PostgreSQL 保存课题、材料、知识卡、产出、研究运行、审核、调用记录及 LangGraph 检查点。
- LangGraph 管理研究简报、采集、知识提炼、大纲、文稿和审核节点。
- Celery/Redis 分发运行，事务 outbox、数据库执行锁和幂等键防止重复执行。
- 原文和产出保存至 S3 兼容对象存储，数据库保存内容哈希及证据关系。
- PostgreSQL 全文检索与 pgvector 支持领域内知识复用，中文使用 jieba 分词。
- OpenTelemetry 与 Langfuse 接入调用观测，数据库独立保存调用用量。

## 状态与可靠性

课题、研究运行、节点和审核分别维护状态。人工确认使用 LangGraph interrupt，审核提交后以相同 thread_id 恢复。原文视为不可信数据。模型结果通过 Pydantic 校验。预算限制在外部调用前检查，错误由运行边界记录并终止，禁止静默降级。重新执行必须明确记录新的执行尝试。

## 数据迁移

旧 SQLite 文件以只读方式读取，迁入 PostgreSQL 并保留主键；迁移前检查目标是否为空，检查原始引用关系，完成后核对各表记录。原始 SQLite 文件保留。

## 验收

在真实 PostgreSQL、Redis、对象存储和浏览器中验证数据库迁移、任务投递、暂停恢复、重复执行、审核版本与接口。模型与搜索完整验证需要实际配置的服务凭据，验证状态在发布说明中如实记录。
