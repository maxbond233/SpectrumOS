# 项目状态与演进方向

当前开发版本：0.5.0。

## 当前实现

研究运行由 LangGraph 管理，PostgreSQL 保存检查点和业务数据，Celery/Redis 分发执行。课题、运行、审核分别记录状态。工作台支持研究简报、大纲及文稿确认、历史版本与证据查看。

知识数据保存原文版本、片段、主张、证据关系、知识卡和产出。研究采集前查询同领域已有材料，检索结合中文分词与本地向量模型。审计、调用次数、实际 Token、耗时及配置单价计算的费用持久保存。

运行入口为 `spectrum run`、`spectrum worker` 和 `spectrum beat`。部署与数据迁移见根目录 README。验证结果见 `v0.5.0-validation.md`。

## 后续研究方向

- 使用固定的真实研究任务集持续评测覆盖度、引用支持程度、人工修改量、费用与耗时。
- 基于知识卡和证据关系研究跨课题知识更新、冲突检测及研究构想生成。
- 根据实际部署需求扩展多人身份认证、项目权限和领域词典管理。

这些方向需要独立的需求、实现和验收记录。
