## 复现

按照 README 启动真实基础服务，执行 `spectrum migrate`，并启动 API、Celery worker。然后执行：

```bash
uv run pytest checks/ -v --tb=short
npm run build --prefix frontend
npm run typecheck --prefix frontend
```

检查使用真实仓库文档和实际业务操作，不注入模型响应。检查产生的课题、审计和迁移数据库保留，以便追溯。迁移验证使用本轮记录生成的 SQLite 文件，未验证用户生产 SQLite 数据库。
